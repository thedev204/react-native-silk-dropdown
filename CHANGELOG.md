# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-25

### Added

- Initial release of `react-native-silk-dropdown`
- Single API for popover and bottom-sheet presentations
- Searchable lists with keyboard-aware layout
- Single- and multi-select (chips, `maxSelected`)
- Animation presets: `fade`, `slide`, `scale`, `spring`, `none`
- Slot `styles` and render props (`renderTrigger`, `renderItem`, `renderChip`, …)
- `DropdownProvider` theming with `tokens` / `darkTokens`
- TypeScript generics with a discriminated `multiple` union
