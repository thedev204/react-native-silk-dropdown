# react-native-silk-dropdown

A smooth, keyboard-safe, fully styleable dropdown for React Native. Popover or bottom sheet, one API.

## Installation


```sh
npm install react-native-silk-dropdown
```


## Usage


```js
import { multiply } from 'react-native-silk-dropdown';

// ...

const result = multiply(3, 7);
```
